---
title: Can't Edit a Document
description: Fix inability to edit documents in rohit singh docs.
---

## Symptoms

- Edit button is disabled
- Changes not saving

## Possible Causes

- No edit access
- Logged out session
- Page locked by another user

## Quick Fix

<Steps>
  <Step title="Check Permissions">
    Ensure you have edit rights for this project.
  </Step>
  <Step title="Login Again">
    Log out and sign back in at https://docs.rohitsingh.com/login
  </Step>
  <Step title="Check for Locks">
    If the page is locked, wait or ask the editing user to finish.
  </Step>
</Steps>
